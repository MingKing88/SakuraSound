樱响 SakuraSound v1.0.0（2026-10-25，首个公开正式版）
本版与 v8.16-test 内容一致，仅版本号正式化：自动基准分层（指定 > 浏览器 > 其他 > 流媒体，按程序名分类）、浅色玻璃＋樱花树背景、安装包默认开机自启动、内置站酷快乐体圆体；不带 PEQ 与音频驱动插件。

樱响 SakuraSound v8.16-test（2026-10-25，安装即开机自启动版）
本版在 v8.15-test 基础上只改安装包：安装时默认写 HKCU Run 开机自启动（值名 SakuraSound，指向安装目录 SakuraSound.exe），无需管理员权限；应用里开机自启动开关首次打开即显示开，关掉开关即删掉该 Run 值；卸载时也删掉它。便携包本身不改注册表，解压即用、仍需手动勾开关。程序逻辑、UI、图标、树图均未改。

樱响 SakuraSound v8.15-test（2026-10-25，自动基准分层版）
本版在 v8.14-test 基础上改动（只动 volrider_core.py 的基准计算段，其他逻辑、UI、图标、树图均未改）：
- 自动基准分层：指定基准应用 > 浏览器 > 其他 > 流媒体；同一层里最响的赢，
  高层只要有出声的未手动调过应用就赢，不管低层多响。
- 分类按程序名字算（SessionInfo.name，即进程名，如 chrome.exe），不是窗口标题、不是内容类型；
  浏览器含 chrome/msedge/edge/firefox/opera/brave/arc/vivaldi/chromium 等，
  流媒体含 spotify/cloudmusic/qqmusic/kugou/kuwo/bilibili/iqiyi/youku/qqlive/tencentvideo/netflix 等。
- 层内仍跑原有最响/顶格锚点/目标上限/目标 60% 下限逻辑；同步后真正拉平，不保留音乐略响的差距。
- 场景：浏览器小游戏＋听歌、LOL/OW＋听歌时，平时音乐比游戏响一点点；分层后游戏/浏览器当基准，
  音乐被拉下来拉平，游戏不再被音乐带高。

樱响 SakuraSound v8.14-test（2026-10-25，浅色玻璃＋樱花树版）
本版在 v8.13-test 基础上改动：
- 改名：VolRider → 樱响（SakuraSound），标题栏“樱响 · 系统响度均衡”，安装目录/发行物名统一为 SakuraSound；
  内部模块名（volrider_core、web/server、主题/设置文件名）未改，旧主题与设置文件可继续用。
- 背景页新增樱花树预设（冷色居中樱花树 sakura-tree-cool.png），新增两个樱花开关：

  两开关值存主题文件、重启恢复；樱花树模式花瓣从树冠起落，自定义壁纸模式从顶部均匀落下。
- 图标换成定稿斜枝樱花图标（sakura.ico，多尺寸 16/32/48/256），旧深色喇叭图标生成逻辑已删。

VolRider v8.13-test（2026-10-25，浅色玻璃＋樱花版）
发行版：内嵌 Python + 预装依赖，解压/安装后双击即用，无需另装 Python 与依赖。
本版变化：分块平均替代长时 EMA（10 个出声样本一块、最近 100 块，约 100 秒出声时间）；
基准应用下拉（自动/指定应用，指定不出声时退回自动，重启后按名恢复）；
固定后漂移重校（相对固定基线偏离 ±3dB 持续约 3 秒则重进相位）。
界面：整套换成浅色玻璃风（粉紫渐变底＋半透明白圆角卡片），主按钮粉紫渐变，
背景樱花飘落动画（可关），应用头像/开关/滑杆手柄/下拉箭头均为樱花元素，
按钮为粉渐变毛玻璃，字体为内置站酷快乐体圆体。
本版仍不带 PEQ 与音频驱动插件，只做系统响度均衡；PEQ 代码归档在 archive/peq-2026-10-25.py。
相位规则不变：拨开开关立刻同步一次，随后每 5 秒一次、满 3 分钟后固定；
新程序出声满 2 秒后同样进入相位，改目标/重开自动只单次同步。
本版在 v8.12-test 基础上：整体字体加大 2px（基础 14px→16px、程序字号 10→11pt、窗口初尺寸 760×900）。
本版追加：飘落花瓣 22→36 片；大图卡顿修（静态背景缓存、原图缩到 1920 快速缩放）；背景页新增毛玻璃透明度滑杆（50–100%，默认 84%，卡片＋按钮一起调）。
